# 🚚 Otimização de Armazém

> Otimização de layout e slotting de armazém com IA. Reduz distância percorrida no picking e aumenta a produtividade operacional.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/otimizacao-armazem/

[![Vertical](https://img.shields.io/badge/Vertical-Logística-blue)]() [![IA](https://img.shields.io/badge/IA-Optimization-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]()

## 📊 Resultados-chave (KPIs)
**+34%** Picking · **-41%** Distância · **+28%** Produtiv. · **120K** SKUs

## 🧠 Tecnologias de IA
Optimization · ML · Operations Research

## ✨ O que faz
- Slotting otimizado por giro
- Redução de distância de picking
- Layout dinâmico
- Análise de fluxo

## 🗄️ Fonte de dados real
[WMS + movimentação](https://www.gov.br)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com WMS + movimentação
2. **Processamento com IA** — Optimization · ML · Operations Research
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
